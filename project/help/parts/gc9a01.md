# GC9A01 Round LCD Controller

## What It Is

GC9A01 is the round LCD controller used by the M5Stack Dial display assembly.

## Init Contract

- Bring up the SPI bus first.
- Reset the panel if a board reset signal is available.
- Send the standard sleep-exit and display-on sequence.
- Apply rotation or backlight policy from project overrides.

## Smoke Test Meaning

A pass means the SPI command path works and any mapped backlight signal responds. It does not guarantee final pixel orientation or full frame-buffer correctness.

## High-Level API Usage

- `display_init`: apply the board-standard startup sequence.
- `display_set_backlight`: control backlight through the board signal.
- `display_write_command`: use low-level commands during bring-up and diagnostics.
