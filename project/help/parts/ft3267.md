# FT3267 Touch Controller

## What It Is

FT3267 is the capacitive touch controller used on the M5Stack Dial touch panel.

## Init Contract

- Bring up the shared I2C bus first.
- Release any reset path before probing.
- Confirm the controller responds at the configured address, normally `0x38`.

## Smoke Test Meaning

A pass means the controller ACKs on I2C and the mapped interrupt line can be sampled. It does not require an active finger touch during boot.

## High-Level API Usage

- `touch_is_present`: report whether the controller responded during setup.
- `touch_read_points`: return current touch coordinates.
- `touch_irq_active`: sample the board-mapped interrupt state for event-driven use.
