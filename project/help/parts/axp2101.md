# AXP2101 PMU

## What It Is

AXP2101 is the power-management device used on the M5Stack CoreS3 for supply-path control, battery charging, and wake behavior.

## Init Contract

- Bring up the system I2C bus first.
- Probe the PMU at its configured address.
- Read power-source state before applying charge or regulator policy.

## Smoke Test Meaning

A pass means the PMU responds on I2C and returns coherent status data. Battery absence is not a communication failure.

## High-Level API Usage

- `pmu_read_status`: inspect supply and battery state.
- `pmu_set_charge_policy`: apply charging defaults for the project.
- `pmu_configure_wakeup`: control wake sources used by the board.
