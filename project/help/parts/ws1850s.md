# WS1850S RFID

## What It Is

WS1850S is the RFID/NFC-facing device wired onto the M5Stack Dial internal I2C bus.

## Init Contract

- Configure the shared I2C bus before device setup.
- Honor the configured reset polarity and settle delay.
- Enable any interrupt handling only after the device responds.

## Smoke Test Meaning

A pass means the device survives reset and responds on I2C at the configured address. An idle interrupt line is acceptable during boot.

## High-Level API Usage

- `rfid_reset`: drive the mapped reset line.
- `rfid_is_present`: report probe success from board bring-up.
- `rfid_poll`: read card or field status from higher-level code.
