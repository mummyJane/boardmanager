# BM8563

## Summary

`BM8563` is the RTC block used for timekeeping on boards such as the M5Stack Dial. It is a reusable device part and should own its own init/setup contract, smoke-test meaning, and high-level API usage.

## Interface

- bus: `i2c`
- default address: `0x51`

## Init And Setup Contract

The part-level init should be responsible for:

- confirming the I2C device responds at the configured address
- reading enough RTC state to prove the device is alive
- applying any safe default configuration needed before higher layers use time functions

Board-level code should only:

- provide the bus binding
- provide any board-local reset or interrupt wiring if present
- call the part init in the correct boot order

## Smoke Test Meaning

A `PASS` for `bm8563` should mean at least:

- the device acknowledged on I2C
- a minimal register read completed successfully

A `FAIL` should mean one of:

- the device did not acknowledge on the expected address
- the bus is not usable yet
- a minimal register transaction failed

## High-Level API Direction

Higher-level code should use a part API, not raw board probes. The expected API shape is along these lines:

- `bm8563_init(...)`
- `bm8563_read_time(...)`
- `bm8563_set_time(...)`
- `bm8563_read_status(...)`
- `bm8563_run_smoke_test(...)`

Board-specific wrappers may expose the board's RTC instance, but they should delegate to the reusable `bm8563` implementation.
