# Help Pages

This folder contains operator and developer help/man pages that the future web interface can render.

## Layout

- `project/help/parts/`: reusable part help covering init, smoke tests, API usage, and references
- `project/help/boards/`: board-level help covering assembly, buses, boot order, and common bench notes

Help pages should stay local to the repo so the web layer can present stable documentation even when vendor sites change.
